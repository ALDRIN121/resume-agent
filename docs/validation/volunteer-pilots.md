# Owner-arranged volunteer pilots

Status: **not run**. No participant has been contacted by the implementation agent. No pilot result is inferred from automated tests.

Arrange five voluntary sessions before broad release. Use participant pseudonyms in the report. Keep source resumes local and permissioned.

## Session procedure

1. Record the candidate revision, operating system, interface and model mode.
2. Record the participant's consent and permitted data use.
3. Start the setup timer before the participant opens the application.
4. Let the participant import and review their profile.
5. Ask the participant to save one complete role description.
6. Let the participant choose whether to evaluate it.
7. Record the first content review and any requested help.
8. Interrupt once at a durable review, then restart.
9. Let the participant recover their saved work.
10. Ask the participant to inspect every PDF fact and page.
11. Record the exact preview and released PDF hashes.
12. Stop the first-reviewed-PDF timer after the participant's final decision.
13. Record errors, factual discrepancies, interruptions and developer assistance.
14. Retain only the data the participant permitted.
