# 3.0.0 — Reliable reviewed resumes

Release candidate, 13 November 2026. Version metadata is prepared; no package, tag or release has been published. The release decision is recorded in the [R1 acceptance matrix](../superpowers/plans/2026-11-13-r1-acceptance.md).

New generation uses durable runs shared by the web app and CLI. Questions, suggested changes, content confirmation and PDF confirmation remain separate decisions. Suggested changes start unselected. Rejecting every change preserves the reviewed wording, and selecting a change shows its result in the complete content preview before confirmation.

A deterministic template renders confirmed content. PDF review binds the content, layout and exact PDF byte hashes. A stale review or replaced canonical PDF blocks release. Downloaded bytes must match the reviewed PDF. Run-owned files and collision-safe exports keep simultaneous applications to the same company separate.

Resume imports retain the complete supported source and parsed draft for comparison. Accepting a reviewed draft replaces the base profile; rejecting it preserves the previous profile. Supported text inputs contain up to 48,000 Unicode characters; uploads contain up to 10 MiB. Larger inputs receive an explicit error. Scanned documents require readable text; OCR is not included.

Saved questions, content decisions and PDF reviews survive restart. Accepted actions replay their saved results. A legacy run recovers into a fresh linked run using its original source, with fresh reviews. Historical PDFs remain labelled unverified unless separately inspected; old approvals do not authorize a new release.

Model calls have one durable retry owner and a maximum of two attempts for a task. Authentication, context limits and truncated output do not automatically retry. Rendering and advisories cannot rewrite the confirmed content.

CI now defines Python 3.12/3.13 checks, frontend tests/build, native Windows lock/path checks, installed wheel/source archive checks, and mandatory browser/PDF acceptance with real API and WebSocket traffic. Local macOS results do not establish Windows or Linux distribution compatibility; those CI jobs must execute successfully before making that claim.
