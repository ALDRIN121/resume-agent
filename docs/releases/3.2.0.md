# 3.2.0 — Local search operations candidate

Prepared locally on 13 November 2026. No package, branch or release has been published. C3 evidence is recorded separately.

Discover reads configured public Greenhouse, Lever and Ashby boards. Source edits require the current configuration revision. Refresh is manual. Scans retain frozen configuration, original response evidence, retry budgets and source results. Restart does not issue requests. Continue and cancellation are explicit.

Complete, partial, failed, empty, interrupted and cancelled scans have separate states. Only a clean complete scan can mark a posting absent. Absence does not prove employer closure. Failed or partial scans preserve earlier jobs and show freshness. Cross-provider similarities remain hints. No scan calls a model, evaluates every role or submits an application.

Select a saved role to inspect its complete description and original provider record. Evaluation, generation and application records retain that exact job snapshot. New provider text does not replace selected evidence. The existing content and final PDF reviews remain mandatory.

Applications records one local attempt at a time. Submission requires a selected released document or an explicit unknown choice. An optional matching evaluation is frozen at submission. Stage changes, responses, reopening and corrections retain the audit. Generated PDFs never become submissions automatically. Outcome reports use explicit events and frozen scores; rates need ten resolved records per band.

The shared CLI adds `discover sources/configure/refresh/inspect/continue/cancel/postings` and `applications list/create/inspect/event`. Structured configuration and events use bounded JSON files. Revisions and action IDs protect against stale or repeated changes.

This candidate has no scheduled discovery, unrestricted search, auto-application, email sending, telemetry or automatic score tuning. Agent JSON access and host-model execution belong to the next stage. Linux and native Windows CI remain unverified here.
