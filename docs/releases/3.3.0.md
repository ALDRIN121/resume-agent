# 3.3.0 — Agent access candidate

Prepared locally on 13 November 2026; recovery fixes reviewed on 14 November. This is a candidate, not a published or production-verified release. Final acceptance and publication are separate.

The new `agent` commands expose generation, inspection, typed responses, cancellation, export, import, evaluation, discovery, memory and application records. Commands return one JSON document and never prompt. They use the same services and review hashes as the web app.

External-agent mode returns durable structured model requests instead of calling a configured backend. Complete inputs, schemas, request IDs and response budgets survive restart. Schema-invalid responses have at most two attempts. Validated results are reused. Candidate-source validation still applies.

Human import, content and PDF decisions remain separate from model results. Final release still copies the exact approved PDF bytes. Host mode disables optional HR and vision calls. It needs no backend key; host subscription or API charges can still apply.

The portable `resume-agent` skill and its complete protocol reference ship in the wheel and source archive. Export it into a chosen project directory. Existing destinations are retained. See [host setup](../agent-hosts.md).

Codex CLI 0.153.4 passed the exported-skill content-review handoff. Claude Code 2.1.285 stopped before inference because its OAuth session expired. Claude integration remains unverified and unsupported in this candidate.

The candidate includes the earlier reviewed-memory, role-evaluation, explicit application, outcome and bounded discovery upgrades. These are local tools and descriptive evidence. They do not establish adoption or predict hiring outcomes.

The final independent branch review found three Important recovery defects. The fixes reuse an owned export reservation after a crash, keep cleanup conflicts local to their run, and let the web app discover, continue or cancel saved imports. New regression tests cover each failure, including a real browser/server crash after profile replacement. See the [review record](../validation/final-branch-review-2026-11-14.md).

Open release gates are owner-arranged volunteer pilots, remote Linux/native Windows certification and authenticated Claude validation. The [R4 acceptance record](../superpowers/plans/2026-11-13-r4-acceptance.md) records local results and exclusions. No registry publication, repository-setting change, employer submission or message has occurred.
